✈️ ANAC Dados Abertos - Consulta de Aeronaves
Este projeto é uma aplicação desenvolvida em Python que consome dados abertos da ANAC (Agência Nacional de Aviação Civil) no Brasil para coletar, processar e exibir informações cadastrais de aeronaves de forma simples e organizada.

🚀 Funcionalidades
Coleta de Dados: Extração de dados públicos e atualizados diretamente das bases de dados abertas da ANAC.

Processamento em Python: Limpeza, tratamento e estruturação dos dados brutos utilizando bibliotecas Python.

Interface Web: Um template em HTML limpo e responsivo para visualizar o cadastro das aeronaves de maneira intuitiva.

🛠️ Tecnologias Utilizadas
Linguagem: Python (Pandas) | HTML | Claude
